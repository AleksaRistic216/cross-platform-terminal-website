
**URL**

**Tagline**
```
The same GPU-accelerated terminal on Windows and Linux, with live status for AI coding agents.
```

**Description**
```
A terminal and workspace that behaves identically on Windows and Linux: the same shortcuts, layout and settings across PowerShell, cmd, Git Bash, WSL and any Linux shell. The grid renders in a single GPU draw call, shells can keep running after the app closes, and panes running Claude Code, Codex, Aider and other agent CLIs show whether each is working, waiting on you, or done.
```

**Standout features** (one per box)
```
One set of keys on both systems: Ctrl+Shift+C and Ctrl+Shift+V copy and paste on Windows and Linux alike, and every action can be rebound.
```
```
Shells that outlive the window: an opt-in background daemon keeps shells running when the app closes, and reopening it reattaches them with scrollback intact.
```
```
Agent-aware panes: recognises Claude Code, GitHub Copilot, Codex CLI, Gemini CLI, Aider, Cursor Agent, opencode and Amp, tells idle, working, waiting, finished and failed apart, and notifies the desktop when one needs you.
```

**What makes this different?**
```
It is one application built identically for both systems, rather than one config file carried between two programs, so the layout, shortcuts and settings screens are the same on a Windows laptop and a Linux desktop. Releases are frequent and dated on the public changelog, and reported bugs are usually fixed the same day.
```

**Who is it for?**
```
Developers who split their week between Windows and Linux, and anyone running several AI coding agents at once who needs to see which one is waiting on them.
```

## Not these, and why

- **awesome-cli-apps, awesome-ai-coding-tools, awesome-claude-code** — their rules require open
  source, a free tier, or no payment. CPT doesn't qualify, so don't submit.
- **awesome-windows** — it accepts paid apps, but its rules ban submissions written with AI. Skip
  it, or write that one entirely in your own words.
- **awesome-terminals** (on GitHub) — probably accepts CPT, but it means editing a file on GitHub
  and waiting weeks for a reply. Later, once the three above are done.
